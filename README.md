# Бот-дневник силовых тренировок

Telegram-бот для учёта силовых тренировок: записывает подходы, считает расчётный максимум на 1 повтор (формула Эпли: `вес × (1 + повторы / 30)`), отмечает новые рекорды, показывает историю и составляет план рабочих весов.

## Команды

- `/add жим 100 5` — записать подход: упражнение, вес (кг), повторы
- `/max жим` — расчётный максимум по лучшему подходу
- `/history жим` — последние 10 записей
- `/plan жим` — рабочие веса 70% × 5, 80% × 3, 90% × 1 от максимума (округление до 2,5 кг)
- `/start`, `/help` — список команд

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

Получи токен бота у @BotFather и запусти:

```bash
export BOT_TOKEN="твой_токен"
python bot.py
```

Записи хранятся в файле `data.json`, он создаётся автоматически.

## Тесты

```bash
pytest
```

## Файлы и функции

**`calculations.py`** — чистые расчёты, без Telegram и файлов, поэтому их легко тестировать.
- `one_rep_max(w, r)` — расчётный максимум по формуле Эпли. При 1 повторе возвращает сам вес: формула дала бы на 3% больше.
- `round_to_plates(w)` — округление до 2,5 кг, чтобы вес можно было собрать блинами.
- `make_plan(rm)` — рабочие веса 70/80/90% от максимума.
- `best_max(entries)` — лучший расчётный максимум по всем записям; по нему считается план и определяется рекорд. Для пустого списка возвращает 0, поэтому первый подход всегда рекорд.

**`parsing.py`** — проверка ввода пользователя. При ошибке выбрасывает `ValueError` с текстом, который бот показывает пользователю.
- `parse_add(text)` — разбирает `жим лёжа 102,5 3`: название может быть из нескольких слов (берутся все слова, кроме двух последних), вес можно писать через запятую. Ограничения 0–1000 кг и 1–100 повторов отсекают опечатки, а также `inf` и `nan`, которые `float` считает числами.
- `parse_name(text)` — приводит название к нижнему регистру и убирает лишние пробелы, чтобы «Жим» и «жим» были одним упражнением.

**`storage.py`** — хранение в `data.json` вида `{id пользователя: [записи]}`.
- `load_data` — если файла нет, возвращает пустой словарь; если файл повреждён, выбрасывает понятную ошибку вместо трейсбека.
- `save_data` — `ensure_ascii=False`, чтобы русские названия в файле читались.
- `add_entry`, `get_entries` — id приводится к строке, потому что ключи в JSON всегда строки.

**`bot.py`** — только обработчики команд: разобрать ввод → прочитать/записать данные → ответить. Все ошибки ввода и файла ловятся через `except ValueError` и отправляются пользователю текстом. Токен берётся из переменной окружения, чтобы не попасть в репозиторий.

**`tests/`** — тесты логики (расчёты, разбор ввода, хранение). Тесты хранения используют `tmp_path` — временную папку pytest, чтобы не трогать настоящий `data.json`.
